🎬 YouTube channel connect

One-time setup — create free OAuth credentials in Google Cloud Console:
1. Go to console.cloud.google.com → create a project
2. APIs & Services → Enable YouTube Data API v3
3. APIs & Services → Credentials → Create OAuth client ID → Application type: Web application
4. In that client, add Authorized redirect URI:
http://localhost:8787/jarvis/callback
5. Copy the Client ID and Client Secret into the boxes below → Save.
6. Press Connect YouTube account and sign in with your channel's Google account.
After Google approves, the Channel ID is captured automatically and filled into the field above.
